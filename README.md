# AI Object Detection and Tracking

A real-time object detection and tracking system built using **OpenCV, YOLOX, and SORT**.

## ✨Features

- Real-time webcam input using OpenCV
- Pre-trained YOLOX object detection model
- Detection of multiple objects
- Bounding boxes around detected objects
- Object class labels and confidence scores
- SORT-based object tracking
- Unique tracking IDs for detected objects
- Supports webcam input and video-file input

## 🛠️Technologies Used

- Python
- OpenCV
- YOLOX
- ONNX
- SORT
- Kalman Filter
- Hungarian Algorithm
- NumPy
- SciPy
- FilterPy
